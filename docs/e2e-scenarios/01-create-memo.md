---
title: 'E2E 테스트 시나리오 1: 새 메모 생성 (Happy Path)'
---

## 1. 개요

-   **시나리오 ID:** `TC-001`
-   **테스트 케이스:** 사용자가 필수 정보를 모두 입력하여 새 메모를 성공적으로 생성하는 과정을 검증합니다. (Happy Path)
-   **사전 조건:** 사용자는 애플리케이션에 접속할 수 있어야 합니다.

## 2. 테스트 단계

1.  **Given** 사용자가 메인 페이지(`http://localhost:3000`)에 접속한다.
2.  **When** `새 메모` 버튼을 클릭하여 메모 작성 폼을 연다.
3.  **And** 아래와 같이 폼 필드를 채운다:
    -   **제목:** `E2E 테스트 메모`
    -   **카테고리:** `업무`
    -   **내용:** `이것은 Playwright를 사용한 E2E 테스트입니다.`
    -   **태그:** `테스트` (입력 후 Enter), `Playwright` (입력 후 추가 버튼 클릭)
4.  **And** `저장하기` 버튼을 클릭한다.

## 3. 기대 결과

1.  **Then** 메모 작성 폼이 닫히고, 메인 페이지의 메모 목록이 화면에 표시된다.
2.  **And** 목록의 최상단에 방금 생성한 `E2E 테스트 메모`가 보여야 한다.
3.  **And** 해당 메모 아이템에는 제목, 내용의 일부, `업무` 카테고리, 그리고 `#테스트`, `#Playwright` 태그가 정확하게 표시되어야 한다.
4.  **And** 페이지 상단의 통계 정보(총 메모 개수)가 이전에 비해 1 증가해야 한다.
