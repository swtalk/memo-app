## 1. 개요

-   **시나리오 ID:** `TC-002`
-   **테스트 케이스:** 사용자가 기존 메모를 조회하고, 내용을 성공적으로 수정한 후 결과가 목록에 올바르게 반영되는지 검증합니다.
-   **사전 조건:** '시나리오 1'에서 생성된 `E2E 테스트 메모`가 목록에 존재해야 합니다.

## 2. 테스트 단계

1.  **Given** `E2E 테스트 메모`가 메모 목록에 표시되어 있다.
2.  **When** 해당 메모 아이템을 클릭하여 상세 뷰어 모달을 연다.
3.  **Then** 모달 창에 다음 정보가 정확하게 표시되어야 한다:
    -   **제목:** `E2E 테스트 메모`
    -   **카테고리:** `업무`
    -   **태그:** `#테스트`, `#Playwright`
    -   **내용:** `이것은 Playwright를 사용한 E2E 테스트입니다.` (전체 내용이 Markdown 형식으로 렌더링되어야 함)
4.  **When** 상세 뷰어 모달의 우측 하단에 있는 `수정` 버튼을 클릭한다.
5.  **Then** 메모 편집 폼으로 전환되고, 기존 데이터가 필드에 채워져 있어야 한다.
6.  **When** 아래와 같이 내용을 수정한다:
    -   **제목:** `(수정됨) E2E 테스트 메모`
    -   **태그:**
        -   기존의 `Playwright` 태그 옆의 `x` 버튼을 눌러 삭제한다.
        -   새로운 태그로 `e2e`를 입력하고 추가한다.
7.  **And** `수정하기` 버튼을 클릭한다.

## 3. 기대 결과

1.  **Then** 편집 폼이 닫히고, 메인 페이지의 메모 목록이 표시된다.
2.  **And** 목록에서 해당 메모의 제목이 `(수정됨) E2E 테스트 메모`로 변경되어야 한다.
3.  **And** 태그가 `#테스트`, `#e2e`로 변경되어 표시되어야 한다. (순서는 무관)
4.  **And** 총 메모 개수는 변경되지 않아야 한다.
