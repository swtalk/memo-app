---

## 1. 개요

-   **시나리오 ID:** `TC-003`
-   **테스트 케이스:** 사용자가 검색과 카테고리 필터 기능을 사용하여 원하는 메모를 정확히 찾아내는지, 그리고 필터 초기화 기능이 올바르게 동작하는지 검증합니다.
-   **사전 조건:** 테스트 시작 전, 아래의 3개 메모가 데이터베이스에 미리 삽입되어 있어야 합니다.

    -   **메모 1:**
        -   제목: `React 공부`
        -   카테고리: `개인`
        -   태그: `프론트엔드`, `React`
    -   **메모 2:**
        -   제목: `DB 설계 회의`
        -   카테고리: `업무`
        -   태그: `백엔드`, `DB`
    -   **메모 3:**
        -   제목: `React와 Next.js 비교 분석`
        -   카테고리: `업무`
        -   태그: `프론트엔드`, `Next.js`

## 2. 테스트 단계

1.  **Given** 3개의 테스트 메모가 목록에 모두 표시된다.
2.  **When** 페이지 상단의 검색창에 `React`를 입력한다.
3.  **Then** 제목에 'React'가 포함된 `React 공부`와 `React와 Next.js 비교 분석` 메모 2개만 목록에 보여야 한다.
4.  **And** 통계 정보가 `2개 메모 (전체 3개 중)`으로 업데이트되어야 한다.
5.  **When** 현재 검색어가 유지된 상태에서, 카테고리 필터를 `업무`로 선택한다.
6.  **Then** `React와 Next.js 비교 분석` 메모 1개만 목록에 보여야 한다.
7.  **And** 통계 정보가 `1개 메모 (전체 3개 중)`으로 업데이트되어야 한다.
8.  **When** `필터 초기화` 버튼을 클릭한다.
9.  **Then** 모든 필터가 해제되어 3개의 메모가 전부 목록에 보여야 한다.
10. **And** 검색창은 비워지고, 카테고리 필터는 '전체 카테고리'로 초기화되어야 한다.
11. **And** 통계 정보가 `총 3개의 메모`로 돌아와야 한다.

## 3. 기대 결과

-   각 단계에서 목록과 통계 정보가 기대한 대로 정확하게 업데이트되어야 합니다.
-   필터 초기화 기능이 모든 필터링 조건을 제거하고 원래 상태로 복원시켜야 합니다.
