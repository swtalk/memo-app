title: 'E2E 테스트 시나리오 4: 메모 삭제'
---

## 1. 개요

-   **시나리오 ID:** `TC-004`
-   **테스트 케이스:** 사용자가 메모를 성공적으로 삭제하고, 해당 메모가 목록에서 즉시 제거되는지 검증합니다.
-   **사전 조건:** '시나리오 2'를 통해 수정된 `(수정됨) E2E 테스트 메모`가 목록에 존재해야 합니다.

## 2. 테스트 단계

1.  **Given** `(수정됨) E2E 테스트 메모`가 메모 목록에 표시되어 있다.
2.  **When** 해당 메모 아이템의 우측 상단에 있는 `삭제` 아이콘(휴지통 모양) 버튼을 클릭한다.
3.  **Then** 브라우저의 기본 확인(confirm) 다이얼로그가 나타나며, "이 메모를 정말 삭제하시겠습니까?" 와 유사한 메시지를 표시해야 한다.
4.  **When** 확인 다이얼로그에서 `확인` 버튼을 클릭한다.

## 3. 기대 결과

1.  **Then** `(수정됨) E2E 테스트 메모`가 목록에서 즉시 사라져야 한다.
2.  **And** 통계 정보의 총 메모 개수가 1 감소해야 한다.
3.  **And** 페이지를 새로고침해도 해당 메모는 더 이상 나타나지 않아야 한다 (DB에서 영구적으로 삭제되었는지 확인).

---

### 대안 경로: 삭제 취소

1.  **Given** 삭제 확인 다이얼로그가 열려 있는 상태에서
2.  **When** `취소` 버튼을 클릭한다.
3.  **Then** 다이얼로그가 닫히고, 해당 메모는 목록에 그대로 남아있어야 한다.
4.  **And** 총 메모 개수는 변경되지 않아야 한다.
